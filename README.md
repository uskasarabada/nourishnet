# NourishNet

**Predict Needs. Connect Communities. Fight Hunger.**

NourishNet helps food drive organizers forecast what a drive will collect, plan the volunteers, boxes, and vehicles to handle it, and route every pound to the verified shelter requests that need it most. Then it learns from the results.

> ⚠️ **Demonstration data.** Every organization, person, and number in this prototype is fictional and generated by `src/data/seed.ts`. The map uses a real city only so streets are visible.

## Quick start

```bash
npm install
npm run dev        # http://localhost:5173
npm test           # algorithm unit tests
npm run build      # production build in dist/
```

Requires Node 18+.

Each feature has its own accent color (Plan green, Drives blue, Shelters coral, Match violet). **Reset demo** in the top banner restores the original data.

## How the predictions work (short version)

A log-linear regression, written from scratch in `src/lib/forecast.ts`:

`pounds = participants × base rate × days^α × season × variety × local track record`

Coefficients are fitted by regularized least squares toward sensible priors, so the forecast is cautious with little data and adapts as drives finish. It reports an 80% range, not a single number. A rolling backtest (each past drive predicted only from earlier drives) gives about **20% average error vs 73% for a rule of thumb**, with about 82% of outcomes inside the 80% range. These figures are for the synthetic data only. Full details: [docs/ALGORITHMS.md](docs/ALGORITHMS.md).
